## 🧪 Testing

### Start the System

**Backend:**
```bash
cd backend/api
python main.py
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

### Test Real-Time Updates

1. Open dashboard at `http://localhost:3000`
2. Train agent: `POST http://localhost:8000/api/v1/train`
3. Analyze a log: `POST http://localhost:8000/api/v1/analyze`
4. Watch threat appear in real-time on dashboard

### Test Compliance Reports

1. Navigate to Compliance page
2. Select report type (SOC2, GDPR, HIPAA)
3. Set date range
4. Click "Generate Report"
5. Review and download report
